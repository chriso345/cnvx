# Contributing to cnvx

All contributions to cnvx are welcome.

## AI usage

AI tools are allowed, but discouraged:

- Write your own changes. Do not vibecode. Contributions that are mostly AI-generated will not be accepted.
- Declare any AI use in your pull request or issue. Specificy which tools were used, and for what purpose.
- Review everything yourself. You must read, build, test, and understand every line you submit, and be able to explain it.
- No autonomous or agent-driven submissions, including bot-opened issues and pull requests.

Any contributions that appear to violate these rules may be closed without detailed review or comment. Repeated violations may result in a ban from contributing to the project.
